# algorithm-c# / c++

C#을 중심으로 알고리즘 문제를 풀이하며 문제 해결 능력과 기본적인 자료구조 및 알고리즘 활용 능력을 키우기 위한 저장소입니다.

백준과 프로그래머스 문제를 중심으로 학습하며, C#의 기본 문법과 주요 자료구조 및 알고리즘을 직접 구현하고 활용하는 것을 목표로 합니다.

## 🛠 Tech Stack

* C#
* C++
* 자료구조 & 알고리즘

## 🎯 Purpose

* 알고리즘 문제 해결 능력 향상
* C# 문법 및 자료구조 활용 능력 향상
* 알고리즘의 기본 원리와 풀이 과정 이해
* 다양한 문제를 통해 논리적 사고 및 문제 해결 능력 향상

## 📚 Platforms

* 프로그래머스

## 📝 Study
